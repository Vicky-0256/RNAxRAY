Local CPLfold

Run longer sequences locally

Use RNAxRay Web to prepare the exact input files, then run bin/cplfold on your own machine for longer or Numba-accelerated jobs.

1. Prepare inputs in the web app

Download the generated files

Keep your RNA Structure tab open. After selecting CPLfold, click Download local inputs below the sequence preview.

cplfold-input.fastaAlways downloaded. It contains the prepared single-record sequence.
cplfold-bonus-matrix.tsvDownloaded for HYB-guided mode. It stores the sparse 1-based bonus matrix built from all eligible HYB rows in the selected reference region.
2. Place files in the repository root

Use the same folder as bin/

The commands below assume the downloaded files are next to the RNAxRay bin/ and requirements/ directories.

rnaxray/
  bin/cplfold
  requirements/cplfold-core.txt
  cplfold-input.fasta
  cplfold-bonus-matrix.tsv
3. Install once

Create a local Python environment

python3.11 -m venv .venv-cplfold
. .venv-cplfold/bin/activate
python -m pip install -r requirements/cplfold-core.txt
4. Run CPLfold

HYB-guided run with bonus matrix

bin/cplfold \
  --sequence-file cplfold-input.fasta \
  --bonus-matrix-file cplfold-bonus-matrix.tsv \
  --beam 20 \
  --delta 5 \
  --max-phase1 3 \
  --max-phase2 1 \
  --model DP09 \
  --beta 0 \
  --alpha 0.5 \
  --output cplfold-results.txt

Sequence-only mode can omit --bonus-matrix-file and --alpha.

Longer than 1,000 nt

Raise the local guard deliberately

The local wrapper keeps a conservative 1,000 nt default guard. On a stronger machine, raise it after checking available memory.

RNAXRAY_CPLFOLD_MAX_NT=2000 bin/cplfold \
  --sequence-file cplfold-input.fasta \
  --bonus-matrix-file cplfold-bonus-matrix.tsv \
  --beam 20 \
  --delta 5 \
  --max-phase1 3 \
  --max-phase2 1 \
  --model DP09 \
  --beta 0 \
  --alpha 0.5 \
  --output cplfold-results.txt
Important

Keep the bonus matrix as downloaded

The web export already uses the format expected by bin/cplfold. Do not transpose the matrix or convert coordinates. The local CLI reconstructs the symmetric matrix before folding.
